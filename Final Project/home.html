Interactive Web Security Sandbox

About This Website

Welcome to our interactive cybersecurity learning platform. Instead of just reading theory, this sandbox lets you test three overlooked web vulnerabilities firsthand: ReDoS, Race Conditions, and Mass Assignment. All labs run safely as client-side browser simulations.

How It Works:

  1. Select a Lab: Choose one of the three security flaws below.
  2. Trigger the Bug: Inspect the vulnerable code and click a payload button to see the exploit in action.
  3. Test the Fix: Flip the Vulnerable / Fixed toggle and run the exact same payload to watch the patch block the attack.
