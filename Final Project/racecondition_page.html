What is a Race Condition?

CWE-362

A Race Condition occurs when multiple concurrent requests access and modify shared data without proper synchronization.

In this scenario, two withdrawal requests read the same balance before either transaction updates it, allowing both withdrawals to succeed and causing an incorrect account balance.

Why it matters

            


            

                When two withdrawals read the same balance before either one
                writes the updated value, the second check still sees the
                original funds — so the account can be drained beyond its
                real balance.
            


            
The fix


            

                Wrap the read–check–write sequence in an
                atomicTransaction so each request sees the latest
                balance. Switch to Fixed and run the same
                double withdrawal: only one $100 payout succeeds.
