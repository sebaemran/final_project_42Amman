What is ReDoS?

CWE-1333

ReDoS occurs when a vulnerable regular expression takes excessive time to process specially crafted input.

Attackers exploit catastrophic backtracking to consume CPU resources, slow an application, and potentially make a service unavailable.

        Why Does the Vulnerable Regex Take So Long?
      


      

        The vulnerable regex explores many possible ways to divide
        the same input into matching groups. The invalid final "!"
        causes these attempts to fail.
      


      

      

        These are illustrative matching attempts,
        not the exact execution order of the regex engine.
      

    


    

      

        03
        
Why it matters

      

      

        A slow username check can tie up server resources.
        Repeated requests may delay sign-ins and other banking services.
        In 2019, Cloudflare reported that a poorly performing regular
        expression in a WAF rule caused a major service disruption.
      

      
The fix

      

        Replace nested repetition with a single character class:
        /^[a-zA-Z0-9]+$/.
        Switch to Fixed and run the same attack:
        the invalid username is rejected without catastrophic backtracking.
